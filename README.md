## 👨‍💼 Sobre mim

<img align="right" alt="Data Analytics" width="360" src="https://raw.githubusercontent.com/abhisheknaiidu/abhisheknaiidu/master/code.gif"/>

Atuo como **Analista de Vendas**, com forte atuação em **análise de dados, inteligência comercial e performance de vendas** no setor de distribuição.

Tenho experiência prática em:

Hoje, meu foco é evoluir na área de dados, aprofundando conhecimentos em **engenharia de dados e estruturação de pipelines**, sempre com visão orientada a negócio.
